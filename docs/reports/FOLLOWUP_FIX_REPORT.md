## 2. 주요 기술적 결정

- 기존 React·TypeScript·자체 보라색 토큰·시스템 서체를 유지하고 새 의존성을 도입하지 않았다. `ait:design`의 기존 화면 보완 원칙을 참고했으며 지정 범위를 넘는 가이드·자산 생성이나 실행은 하지 않았다.
- 오류 비교는 기존 `policy.inputs`의 정규화 함수를 사용하고 null이면 기존 원문 비교를 유지한다. 새 닉네임 정규화·길이·금액 상한을 정하지 않았다. 빈 이름끼리는 중복 관계로 취급하지 않아 다른 빈 필드의 오류를 불필요하게 갱신하지 않는다.
- 화면/차례 전환 시의 기존 오류 초기화와 제출 시의 첫 오류 초점 이동은 유지했다. 같은 화면에서 필드만 편집할 때 전체 오류를 지우던 처리를 교체했다.
- 결과 검증은 이미 저장된 현재 라운드의 응답 점수를 기준으로 한다. 재추첨하거나 정책 미승인 질문을 주입하지 않는다. 호출자가 결과 객체·배열을 나중에 바꿔도 저장된 스냅샷을 함께 바꾸지 않도록 현재 상태에서 복제한다.
- 당첨 결과는 제목의 접근성 설명으로 전달한다. 일반 회전·동작 감소·복귀 경로 모두 기존 단일 결과 확정 뒤 같은 결과 화면으로 들어간다. 공유 안내에서 결과로 직접 돌아와 제목에 다시 초점이 가면 같은 설명을 다시 읽을 수 있다. 자동 발표 1회와 실제 보조기기의 낭독 동작은 실행 검수 전까지 보장하지 않는다.
- 점수 상태 영역의 DOM 제거는 확인했으나, 가림 직전 보조기기가 예약한 낭독 큐까지 취소된다고 보장하지 않는다.

파일 읽기·검색·패치만으로 정적 검토했다. 테스트, 프로젝트 스크립트, npm, 타입 검사, 빌드, 서버, 브라우저는 실행하지 않았다. `package.json`에는 test 스크립트가 없어 임의 테스트 명령을 만들어 실행하지 않았다.

`git status --short` 읽기 시도는 저장소 소유자 불일치(`dubious ownership`)로 실패했다. Git 전역 설정을 바꾸거나 우회 옵션을 적용하지 않고 파일 직접 열람으로 검토했다. 따라서 Git diff 기반 전체 변경 확인은 미수행이다.

실제 앱 화면에 접근할 실행·브라우저 조작을 하지 않았으므로 캡처를 첨부하지 않는다. 기존 `SCREEN_PREVIEW.html`은 실제 수정 화면 캡처로 간주하지 않았다.
