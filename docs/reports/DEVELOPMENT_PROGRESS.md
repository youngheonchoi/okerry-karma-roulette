## 적용 내용

| 항목 | 변경 |
| --- | --- |
| D01 일반 웹 뒤로가기 | 브라우저 뒤로와 내부 버튼이 같은 전환 함수를 사용한다. 설정 초안은 보존하고 개인 응답은 전달 화면으로 가린다. 회전 중에는 화면을 이탈하지 않아 같은 추첨을 유지한다. 모드 선택에서는 브라우저 기본 이탈을 허용한다. History에는 탐색 표식만 저장하고 응답은 저장하지 않는다. |
| 설정 변경 확인 | 전달·전체 응답 확인 화면에서 확인 후 참가자 설정으로 돌아갈 수 있다. 명단·모드·총액 초안은 유지하고 응답·점수·결과·문항 스냅샷을 초기화한다. 취소하면 진행 상태를 유지한다. |
| QAR-03 결과 복귀 | 공유 안내에서 브라우저 뒤로를 눌러도 기존 결과로 돌아가며 결과를 재생성하지 않는다. |
| QAR-01 재진행 무반응 | 질문·입력 기준이 없으면 독박 재진행 버튼을 비활성화한다. reducer도 미승인 재진행에 사유를 반환한다. 정상 재진행은 결과 화면에서만 수용한다. |
| D06 N빵 재진행 설명 | 연결된 정책에 따라 금액 유지 또는 초기화·재입력 여부를 확인창 본문과 접근성 설명에 포함한다. Q06 자체는 확정하지 않았다. |
| R01·R02 응답 화면 | 상단에 가리기 동작을 추가하고 현재 참가자의 차례를 표시한다. |
| 실행 기반 | 의존성 잠금 파일, Vitest 단위 테스트, Playwright 모바일 WebKit 테스트 및 실행 명령을 추가했다. |
| 의존성 | npm audit에서 보고한 Vite 취약점 수정을 위해 8.0.11 → 8.3.8로 업데이트했다. 업데이트 후 설치 검사 결과 취약점 0건. |

## 검증 결과와 범위

- 단위 테스트 27개 통과: 점수 하한·중복 선택·선택 해제, 입력 경계, 가중 추첨의 전체 티켓 분포, 배분 검증 계약, 공유 투영, 응답 가림·완료 구분, 위조·이전 라운드 결과 거부, 설정 변경·공유 복귀·재진행 초기화.
- 모바일 WebKit 테스트 2개 통과: 브라우저/내부 뒤로의 명단·금액 보존, 모드 선택에서 탐색 경계 해제, 2명 삭제 차단, 중복 오류 국소 갱신, 320px 가로 넘침, 정책 미확정 시작 차단, 새로고침 초기화.
- `npm run typecheck`, `npm run build` 통과.
- 정책이 필요한 상태 전이는 운영 권고안과 다른 합성 데이터로 단위 검증했다. 브라우저에서는 현재 접근 가능한 설정 흐름을 검증했다. 운영 정책 확정 후 질문→결과 전체 브라우저 검수가 필요하다.

## 남은 작업

- Q01~Q08은 이번 작업에서 확정하지 않았다. `src/policy.ts`의 운영 정책은 null을 유지한다.
- 원문 질문 연결, 실제 금액 배분, 질문 공개 동의, 공유·복사 및 서비스 링크 연결은 정책 결정 후 진행한다.
- 앱인토스 SDK·호스트 backEvent와 실제 WebView는 연결·검증하지 않았다. D01은 일반 웹 대응을 완료한 상태다.
- 스크린리더 낭독, 실제 기기에서의 전달·OS 화면 미리보기, 회전 중 복귀와 시각적 당첨 영역은 후속 검수가 필요하다.
- 배포·push·콘솔 등록은 수행하지 않았다.
