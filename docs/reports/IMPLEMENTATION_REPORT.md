## 3. 주요 기술적 결정과 정책 경계

- 추가 상태 관리·라우터·UI·서버 라이브러리 없이 React reducer를 사용했다. 기존 디자인 체계가 없어 한국어 시스템 서체·보라색 중립 토큰을 사용했다. 토스 브랜드나 TDS 인증을 표현하지 않는다.
- 의존성 버전·Node 24 기준은 로컬 앱인토스 플러그인 0.4.0의 `shared/templates/react-vite/package.json`에서 확인한 값을 정확 버전으로 기록했다. npm 레지스트리 조회·설치·호환성 실행 확인은 하지 않았다. SDK·devtools는 Q07/Q08 환경 미확인으로 추가하지 않았다.
- Q01: 문항 승인·버전·상한 선택을 포함한 `QuestionPolicy`가 없으면 시작할 수 없다. 선택 ID를 Set으로 중복 제거하고 `max(20,100+합)`을 bigint로 계산한다. 승인된 상한 없음은 내부 `maximumScore: null`이며, 승인 없음인 `questions: null`과 구분한다.
- Q02: 100원 혼합안·최대잔여법 중 어느 것도 배분 함수에 넣지 않았다. `calculateSettlement()`는 항상 명시적인 pending을 반환한다. 미래 승인 배분 결과는 `validateSettlement()`로 인원·ID·비음수·정수 bigint·정확 합계를 검증해야 한다.
- Q03: 공개 동의·최대 3문항·선정 기준·펼침 조작을 승인으로 가정하지 않았다. 현재 결과에는 질문·응답을 렌더링하지 않는다.
- Q04: 완료 응답 재열람·수정 기능은 보류했다. 뒤로가기로 이전 참가자 응답을 자동 복원하지 않는다.
- Q05: 20자·99,999,999원·trim/NFC를 임시 운영 제한으로 넣지 않았다. 최소 확정 요구인 빈 값·동일 원문 중복·양의 정수만 초안 편집에서 검증한다. 확정 `InputPolicy`가 없으면 실제 라운드 시작은 불가하다.
- Q06: 메모리만 사용하고 영속 저장·자동 복구는 추가하지 않았다. 이는 승인된 최종 새로고침 정책이 아니다. N빵 금액 유지 선택 없이는 같은 참가자 재진행을 제공하지 않는다.
- Q07: 공유/복사 API·서비스 주소를 하드코딩하지 않았다. 공유용 독박 projection에는 질문·응답 필드가 없으며 확정된 결과에서 참가자·당첨자·점수·확률만 가져온다. 실제 플랫폼 전송·복사 fallback은 결정 후 구현해야 한다.
- Q08: 스택은 이번 명시 지시를 적용했다. 앱인토스 SDK·호스트 내비게이션·실기기 연결은 준비되지 않았다. 웹의 자체 이전 단계 버튼을 호스트 환경에 그대로 사용하는 것으로 간주하지 않는다.

독박 추첨은 crypto 난수의 rejection sampling과 bigint 누적구간으로 수행한다. 정수 ticket은 `[0,총점)`이며 화면용 반올림 확률을 난수 분포에 사용하지 않는다. 추첨은 클릭 핸들러에서 한 번 고정하고, 결과 발표와 회전은 그 결과를 따른다. 렌더·StrictMode reducer에서 난수를 생성하지 않는다. 표시할 수 없는 극단 점수는 시각화 오류로 보류하고 임의 점수로 자르지 않는다.

## 5. 미해결 문제 및 주의사항

1. Q01/Q05 승인 전 실제 응답·추첨 경로를 사용할 수 없다. 승인 문서와 `src/policy.ts`를 함께 갱신한 뒤 후속 검증이 필요하다.
2. Q02 공식·Q03 공개 계약·Q04 수정·Q06 복구/금액 유지·Q07 링크/SDK가 미결이다. 이를 임의 기본값으로 우회하지 않았다.
3. 앱인토스 호스트 뒤로·내비 중복·안전영역 SDK·공유 브리지·핀치 설정을 연결하지 않았다. 모바일 웹 기본 CSS env 여백만 작성했다.
4. 설치물과 lockfile이 없고 타입 검사·빌드·테스트를 하지 않아 컴파일·런타임·패키지 해결 성공을 보장하지 않는다.
5. 실행 금지 조건에 따라 브라우저를 구동하지 않았다. `SCREEN_PREVIEW.html`은 소스 기준 정적 참고이며 실행 화면·스크린샷으로 대체 주장하지 않는다. 화면 캡처 1~2장과 실제 시각 검수는 미완료다.
6. 응답 subtree 제거는 앱 내부 UI 보호다. 타인이 준비 버튼을 누르는 행위, 옆에서 보기, OS 화면 캡처를 막는 인증 기능은 없다.

## 가정

- 정식 루트는 UX 초안의 대체 위치 안내와 해당 경로의 `.git`·mvp·PM 문서 실재로 확인했다.
- 미승인 권고안 적용 없이 확정 요구 소스와 pending 화면을 작성하는 것이 이번 1/3단계의 범위다. 전체 MVP 완료를 의미하지 않는다.
- 최초 두 개 빈 참가자 행은 편집 편의를 위한 화면 초안이다. 랜덤 이름 후보는 mvp 예시 8개를 재사용하며 소진 시 직접 입력 안내를 한다.
- 이번 지시의 실행 금지는 패키지 명령·개발 서버·컴파일·테스트·렌더 스크립트에 적용했다. 파일 읽기·쓰기 및 정적 검색만 수행했다.

## 대표 확인 필요

다음 명령은 실행하지 않았다. 정책 결정과 실행 허용 이후 담당자가 검토할 명령이다.

| 보류 명령 | 목적 |
|---|---|
| `npm install` | 의존성 설치·lockfile 생성 |
| `npm run typecheck` | 실제 TypeScript 검사 |
| `npm run build` | 번들 생성 확인 |
| `npm run dev -- --host 127.0.0.1` | 브라우저·접근성·화면 캡처 검수용 로컬 실행 |

테스트 실행 명령은 테스트 도구를 아직 추가하지 않아 정의하지 않았다. 삭제·배포·push·외부 전송 명령은 계획하거나 실행하지 않았다. 사무실 결과물 보고는 이번 업무에서 요청한 앱 보고 첨부에 한정한다.
