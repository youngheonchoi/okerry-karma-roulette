## 정책 의존성

- Q01은 응답 점수, 룰렛 확률, N빵 가중치의 공통 입력이다.
- Q02 결정 전 F06 구현은 계산 함수 계약을 잠정 상태로 둔다. 결과 화면 UI는 확정된 금액 배열을 소비하도록 분리한다.
- Q03은 결과 화면과 공유 경계를 함께 결정한다. 질문은 공유 payload에서 계속 제외한다.
- Q04~Q06은 전달·복귀·재진행의 데이터 생명주기 결정이다.
- Q07은 외부 네트워크가 아닌 공식 플랫폼 기능의 확인 작업이다. API 연계는 프로젝트·SDK 버전을 확인한 뒤 진행한다.
- Q08은 기술 선택 검토만 포함한다. 저장소를 확인하기 전에 프레임워크나 UI 라이브러리를 지정하지 않는다.
